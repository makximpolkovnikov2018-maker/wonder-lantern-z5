# Конвертер звуков для SHUTTER

Конвертер принимает исходный `MP3` или `WAV` и создаёт файл, который может читать карточный модуль Nikon Z 5.

## Ограничения камеры

Готовый файл должен иметь следующие параметры:

- WAV с обычным заголовком размером 44 байта
- несжатый PCM
- 48 000 Гц
- 16 бит
- 2 канала, стерео
- полезная аудиодатa не меньше 2000 байт
- максимум 240 KiB аудиоданных
- максимальная длительность примерно 1,28 секунды

Расчёт максимальной длительности:

```text
240 × 1024 байта / (48 000 × 2 канала × 2 байта) = 1,28 секунды
```

Размер всего WAV-файла вместе с 44-байтным заголовком не превышает примерно `245 804` байта. Для совместимости ориентируйтесь на ограничение аудиоданных `240 KiB`.

При превышении лимита конвертер обрезает звук до допустимой длины и добавляет короткое затухание в конце. Начало звука должно находиться в самом начале файла. Длинная тишина в начале записи будет восприниматься как задержка срабатывания звука.

## Установка ffmpeg

Для MP3 нужен `ffmpeg`. Проверьте его наличие:

```powershell
ffmpeg -version
```

Если команда не найдена, установите FFmpeg для Windows и добавьте его папку `bin` в системную переменную `PATH`. После изменения `PATH` откройте новое окно PowerShell.

## Конвертация MP3 из командной строки

Перейдите в корень репозитория и выполните:

```powershell
python .\tools\make_snd_wav.py .\my-sound.mp3 --out .\build\sound-1
```

Результат:

```text
build/sound-1/SND.WAV
build/sound-1/manifest.json
```

Переименуйте `SND.WAV` в нужный номер:

```powershell
Rename-Item .\build\sound-1\SND.WAV 1.WAV
```

Затем скопируйте `1.WAV` на карту:

```text
A:\SHUTTER\1.WAV
```

Номера от `1.WAV` до `5.WAV` соответствуют пяти слотам звуков в меню камеры. Не обязательно заполнять все пять слотов.

## Конвертация через графическое окно

В исходном репозитории есть окно `tools/windows_packager/audio_app.py`. Оно позволяет выбрать MP3 или WAV, выбрать номер от 1 до 5 и сохранить готовый файл на компьютере. Существующий файл не перезаписывается, поэтому при замене сначала удалите старую копию или выберите другое место.

Запуск окна из корня репозитория:

```powershell
python .\tools\windows_packager\audio_app.py
```

В окне выберите MP3, номер звука и папку сохранения. После завершения скопируйте полученный `1.WAV`–`5.WAV` в папку `SHUTTER` на карте.

## Проверка результата

Конвертер создаёт `manifest.json`. В нём указаны исходный формат, длительность, размер результата, факт обрезки и контрольная сумма.

Быстрая проверка WAV:

```powershell
@'
import struct
from pathlib import Path
p = Path('.\\build\\sound-1\\1.WAV')
b = p.read_bytes()
assert b[:4] == b'RIFF' and b[8:12] == b'WAVE'
assert struct.unpack_from('<H', b, 20)[0] == 1
assert struct.unpack_from('<H', b, 22)[0] == 2
assert struct.unpack_from('<I', b, 24)[0] == 48000
assert struct.unpack_from('<H', b, 34)[0] == 16
assert b[36:40] == b'data'
assert 2000 <= struct.unpack_from('<I', b, 40)[0] <= 240 * 1024
print('Z5 SHUTTER WAV: OK', len(b), 'bytes')
'@ | python -
```

Файл не записывается на карту автоматически. Это позволяет прослушать результат и сохранить резервную копию старой версии.
